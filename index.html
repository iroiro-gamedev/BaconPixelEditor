Basic Workflow
  1. File → New to create a canvas (8–512 px).
  2. Pick a color from the palette, then draw on the canvas.
  3. Add layers (+L) or frames (+F) for animation.
  4. File → Export as PNG / GIF / Sprite Sheet.
  5. File → Save (.bpe) to save your project.
